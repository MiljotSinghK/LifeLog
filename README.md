# **LifeLog**

### Description:

LifeLog is exactly it's name ,a log book for life ,you can store your life here ,whether it be reminders for daily use or a record for hobbies ,tasks ,etc.



#### Problem Statement:

We generally make no record of our life ,event ,choices ,tasks ,daily habits ,preferences and hobbies .Whenever we wish to state about ourselves ,we tell our life story to other but is incomplete without these things .We can't even have good reminders .I found it a little hard to maintain record on my notepad and didn't like the UI so I got this idea to build a good UI and functioning project to solve this .

### Pros/Best Points:
1\. Has a lot of features such as dark mode and users can choose which tabs they wish to keep .

2\. Clean look and good color combination. 



### Cons/Shortcomings:
1\. Uses too much event listeners, forEach loops and DOM element properties for making the more dynamic and interactive but slows down too and is difficult to explain and manage.

2\.The idea is expandable but to an extend ,then it starts becoming repetitive.



### Usage

1\. Clone or download the project files

2\. Open `LifeLog.html` in any modern web browser

3\. Navigate through the homepage and various logs using the menu

4\. Toggle dark mode using the checkbox on the home page

5\. Explore various interests and make your own personalized lists
